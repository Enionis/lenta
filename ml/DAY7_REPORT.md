# Day 7 — Очистка OCR-токенов + alt-bbox matching + fuzzy price

## Главная находка дня

Отладил один сматченный track в 43_15. OCR выдавал:
```
"679'"  h=65  conf=0.99   ← реальная цена_card, апостроф в конце
"99"    h=20  conf=0.99   ← копейки 679.99
"97J""  h=16  conf=0.80   ← реальная цена_default 973 (J вместо 3)
"30%а"  h=29  conf=0.40   ← скидка -30%
```
А парсер возвращал `price_card=13`, `price_default=99` — потому что `re.fullmatch(r"\d+", "679'")` не matches, и токен полностью отбрасывался.

## Что сделано

### 1. Очистка токенов перед парсингом цен
Новая функция `clean_token_to_number`:
- Расширенная таблица OCR-замен: `J→3`, `T→7`, `g→9`, `q→9`, и т.д.
- Срезает мусор по краям: `"679'"` → `"679"`, `"97J\""` → `"973"`.
- Сохраняет десятичный разделитель и пробел между рублями и копейками.

### 2. Nearest-neighbor склейка rub+kop
Раньше склеивали только если копейки идут **сразу следом**. Теперь:
- Для каждого «рубли» (3–5 цифр) ищем «копейки» (ровно 2 цифры) в окне ±3 токена.
- Проверка по высоте шрифта: kop обычно 25–110% от рублёвого.
- Не использованные «копеечные» токены не идут в цены (раньше шумели).

### 3. Alt-bbox matching в evaluator
Каждый pred-трек теперь хранит `alts_json` со ВСЕМИ K=3 (ts, bbox). При матчинге с GT перебираем не только основной bbox, но и все альтернативы — находим лучшую пару.

### 4. Fuzzy price match
В evaluate_final: цена считается совпавшей если:
- exact, ИЛИ
- `|a - b| / a ≤ 0.01` (1% относительной ошибки), ИЛИ
- `int(a) == int(b)` (рубли совпали, копейки шумят).

### 5. Чистый submission CSV
- `final_<video>.csv` — финальный CSV в формате ТЗ (без служебных колонок).
- `final_eval_<video>.csv` — копия с `alts_json` для нашего эвалюатора.
- `build_final_csv.py --keep_alts` для генерации eval-версии.

## Что НЕ улучшилось на 25_12-20 и почему

25_12-20 продолжает быть «трудным» видео:
- Pred=31 при GT=57 — мы пропускаем половину ценников.
- price_default/_card = 0 — несмотря на улучшения парсера.

Главная причина — этот корпус видео сильно отличается:
- разрешение/освещение хуже,
- цены написаны с шрифтом, у которого OCR пуляет много мусора,
- много мелких ценников за стеклом.

Полностью решается переобучением YOLO с включением 25_12-20 как hard cases (день 8 в плане).
