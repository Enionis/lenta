# План работы ML/CV части: Распознавание ценников (20 дней)

## Общая информация
- **Задача**: Автоматическое распознавание ценников с видео робота
- **Метрика**: Доля ценников с ≥80% точностью распознавания полей
- **Ключевое поле**: `barcode` (первичный ключ для сопоставления с GT)
- **Выход**: CSV с 30 полями (19 ценник + 11 QR)
- **Ограничения**: Локальное развертывание, без облачных API, легковесные модели
- **Целевая платформа**: RKNN (int8) - опционально

## Используемый стек
```
Детекция:        YOLOv8n / YOLO11n → ONNX
OCR:             PaddleOCR PP-OCRv4 mobile (det+rec) → ONNX
QR/Barcode:      pyzbar + OpenCV QRCodeDetector
Трекинг:         ByteTrack (встроен в ultralytics)
Выбор кадра:     Лапласиан + площадь bbox
Язык:            Python 3.10
Формат моделей:  ONNX (универсально, путь к RKNN)
```

### День 7: Выбор лучшего кадра
**Цель**: Реализовать выбор оптимального кадра для OCR

**Задачи**:
- [ ] Реализовать оценку качества кадра:
  ```python
  def estimate_frame_quality(frame, bbox):
      x1, y1, x2, y2 = bbox
      roi = frame[y1:y2, x1:x2]
      
      # Лапласиан (резкость)
      laplacian = cv2.Laplacian(cv2.cvtColor(roi, cv2.COLOR_BGR2GRAY), cv2.CV_64F).var()
      
      # Площадь
      area = (x2 - x1) * (y2 - y1)
      
      # Средний confidence от детектора
      
      # Итоговый score
      score = laplacian * np.log(area) * conf
      return score
  ```
- [ ] Для каждого track_id сохранять историю кадров с оценками
- [ ] Выбирать лучший кадр по максимальному score
